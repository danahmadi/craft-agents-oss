Upgrade the application and server Sharp pins from 0.34.5 to 0.35.5 to address the six direct Sharp Dependabot alerts.

The root build package directly consumes platform-native modules when assembling the standalone server. Declare those modules as optional dependencies matching Sharp 0.35.5. This gives Bun's existing hoisted installer an explicit root requirement, while the Claude SDK retains its separately nested 0.34.x native dependency and libvips. No override, custom filesystem link, SDK upgrade, or runtime/linker change is used. Validate a clean installation because an incremental tree can retain stale nested binaries.

The standalone packager now also includes Sharp's detect-libc and semver dependencies. An actual Linux package failed outside the source checkout because detect-libc was omitted; testing inside the repository had hidden that omission through ancestor node_modules. `bun run test:server:package <distribution>` copies the complete assembly to a temporary location outside the checkout, refuses ancestor node_modules, disables automatic package installation, and runs the real native image tests using the packaged Bun. It preserves the relocated artifact for inspection.

Validation:
- Frozen install, all required typechecks and validate:ci pass on Bun 1.3.10. The CI suite includes five native image tests: SVG metadata, PNG resize/round-trip, JPEG encoding, AVIF decode/conversion and malformed-input rejection.
- Electron bundle build and the normal macOS ARM64 standalone-server build pass. The relocated assembly passes all five image tests using its packaged Bun 1.3.9. Electron 42.11.18's embedded Node 24.19 runtime also loads Sharp and resizes an image in ELECTRON_RUN_AS_NODE mode, without launching the application.
- Linux glibc source/native and relocated-package verification is required before merge; the exact-head result is recorded in the PR.
- Broad source suite: 3,087 passed, 12 skipped, six failed and one Electron import error, versus main's 3,082 passed, 12 skipped, six failed and the same import error. Named failures match; the five additional native image tests pass. The broad suite is not fully passing. The baseline's missing lint script remains unchanged.

Known residual SDK exposure: Claude Agent SDK 0.2.72 embeds Sharp 0.34.5 and its own native libraries (libvips 8.17.3, libheif 1.20.2, librsvg 2.61.2). Those versions predate the advisory fixes. This PR patches the direct app/server image pipeline; it does not establish that SDK image processing is safe. Actual exploitability through a particular SDK input path is unproven. A parent SDK migration needs separate executable, interceptor and packaging compatibility work; no ABI override or decoder suppression is applied here. The six Pi advisories also remain for a separately approved adapter migration.
